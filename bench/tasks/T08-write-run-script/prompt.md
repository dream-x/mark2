Write a Python script named `fizzbuzz.py` in the current working directory, then
run it and confirm its output.

The script must print the numbers 1 through 15, one value per line, with these
substitutions:

- print `Fizz` instead of the number when it is divisible by 3
- print `Buzz` instead of the number when it is divisible by 5
- print `FizzBuzz` instead of the number when it is divisible by both 3 and 5

So the expected output is exactly these 15 lines:

```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```

Rules:

- The script must be runnable as `python3 fizzbuzz.py` and print nothing else:
  no header, no trailing summary.
- It must use only the Python standard library.
- Run `python3 fizzbuzz.py` yourself and check that the output matches the 15
  lines above before you finish.
