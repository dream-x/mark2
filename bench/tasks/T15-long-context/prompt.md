The `minutes/` directory contains the minutes of six budget meetings, in
chronological order (`shard-01.md` ... `shard-06.md`).

Figures are often revised in later discussion: a later decision supersedes an
earlier one, and a department's final figure may be settled in a later meeting
than the one that introduced it. Read all six files. Determine the approved
annual budget of EVERY department, then report the grand total.

Rules:

- Print the answer as the final line of your reply, in exactly this form:
  `total_budget = <value>` (an integer, no commas, no currency sign).
- Use the `total_budget = ...` form only for that final answer line. Do not
  write it with any other value anywhere in your reply.
- This is a read-only task: do not modify, create or delete any file. That
  includes scratch notes and helper scripts: if you need to calculate, do it
  inline, for example with `python3 -c "..."` or `echo $((...))`.
