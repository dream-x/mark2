Build a small kanban board web app in the current directory: an aiohttp backend `server.py`, started as `python3 server.py`, that listens on the port from the `PORT` environment variable (default 8770) and serves the page at `/`, and a plain JavaScript frontend with no frameworks, no build step and nothing loaded from the internet. The board has three columns, To Do, Doing and Done, behind a JSON API: `GET /api/cards` returns the list of all cards, each an object `{"id": ..., "title": ..., "column": ...}` with a unique id and the column `todo`, `doing` or `done`; `POST /api/cards` with `{"title": ...}` creates a card in `todo` and returns it, or answers 400 when the title is blank; `PATCH /api/cards/<id>` with `{"column": ...}` moves the card and returns it, or answers 400 for an unknown column; `DELETE /api/cards/<id>` removes the card; and both of the last two answer 404 for an id that does not exist. Every change is saved, before the server answers, to a JSON file at the path from the `BOARD_FILE` environment variable (default `board.json`; no file yet means an empty board), so the board survives a restart of the server, even a hard kill. The page has a text input `#new-card` and a button `#add-btn` that adds a card with the typed title (pressing Enter in the input does the same), and column elements `#todo`, `#doing` and `#done` that hold one `.card` element per card, showing its title, with the buttons `.move-left` and `.move-right` to move it to the neighbouring column (they may be missing or disabled where there is none) and `.delete`; the page changes the board only through the API, loads it when it opens and always shows it exactly as the server stores it. Write `test_board.py`, an automated test that starts `server.py` itself as a subprocess on a free port with its own temporary `BOARD_FILE`, checks the API, stops the server even when a check fails, finishes within 60 seconds and exits 0 only if everything works, then run it and make it pass. `python3` on your PATH already has aiohttp, so install nothing, and stop any server you started before you finish.
